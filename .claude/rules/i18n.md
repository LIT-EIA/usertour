# Internationalization

Translations live in `packages/shared/i18n/src/en-US/` and `packages/shared/i18n/src/fr-CA/`.

- All user-facing text must be translatable: no hard-coded UI strings.
- Add every new key to **both** `en-US` and `fr-CA`, at the same path. For official Canadian French terminology, use the `termium-review` skill.
- Keys are descriptive, grouped by feature, and hierarchical. Use placeholders for dynamic content.

```tsx
import { useTranslation } from 'react-i18next';

const MyComponent = () => {
  const { t } = useTranslation();
  return <div>{t('key.path')}</div>;
};
```
